# 정적 GUI 화면 예시

사진 선택·미리보기·모의 결과 화면을 휴대전화 브라우저에서 확인하는 정적 공유본이다. 실제 자세 분석은 제공하지 않는다. 사진은 브라우저 메모리에서만 사용하며 서버로 전송하지 않는다. 탭을 닫거나 새로고침하면 선택한 사진과 결과가 사라진다.

GitHub Pages의 HTTPS 주소로 접속한다. PC와 휴대전화 사이의 Wi-Fi 연결이나 PC 서버 공개는 필요하지 않다. 페이지를 처음 받는 인터넷 연결은 필요하다. Android Firefox 실기기 동작은 사용자가 확인해야 하며 데스크톱 브라우저 결과로 대체하지 않는다.

## 사용 순서

1. 촬영 안내를 확인하고 사진 한 장을 선택한다.
2. 사진 바로 아래의 선택 완료 또는 오류 안내를 확인한다.
3. 모의 결과 보기 버튼으로 화면 예시를 확인한다. 사진 선택만으로 분석을 시작하지 않는다.
4. 사진 지우기로 선택한 사진을 제거한다.

## 재현 가능한 빌드

프로젝트 루트에서 `cd frontend` 후 `npm ci`, `npm run build:offline`을 실행한다. 결과 파일은 프로젝트 상대 경로 `etc/offline-demo/ai-generated-chopcoach-offline.html`이다. 이 경로는 각 컴퓨터의 프로젝트 폴더를 기준으로 해석한다.

빌드 스크립트는 촬영 안내 이미지 두 장·JS·CSS를 하나의 HTML에 넣고 시스템 글꼴을 사용한다. CSP는 네트워크 연결을 차단하고 해당 인라인 JS·CSS의 SHA-256 해시만 허용한다. 배포 대상으로 복사하는 파일은 검증한 HTML을 이름만 바꾼 `index.html`과 빈 `.nojekyll` 두 개다. `etc/` 폴더, 원본 사진, 인증 파일, 로그와 서버 코드는 게시하지 않는다.

Pages 게시 브랜치는 `gh-pages`이며 소스 변경 검토 PR과 별도로 관리한다. `main`의 코드를 병합하거나 분석 API를 인터넷에 공개하는 절차가 아니다.
