# 사진 촬영 안내 이미지

2026-10-09 당일 사용자 제공 일러스트 두 장을 GUI 사진 선택 영역에 추가했다. 젓가락을 벌린 모습과 모은 모습을 함께 보여주고, 손가락과 젓가락을 프레임에 담아 현재 모습 한 장을 촬영하도록 안내한다.

이미지는 `frontend/src/assets/guide-hold-open.png`와 `guide-hold-closed.png`에 보관하며, 제공된 1254×1254 PNG의 바이트를 그대로 사용한다. CSS가 표시 크기를 조절하며 Vite가 로컬 빌드 자산으로 포함한다. 사용자 개인 원본 폴더를 HTTP로 공개하지 않는다.

이 자료는 촬영 구도 안내용이며, 파이프라인 분석 기준사진이나 검증된 정답 자세로 등록하지 않는다. 두 모습 모두 촬영해 업로드할 필요는 없다. 기존 입력은 사진 한 장이며 기준 ID/version·운동 종류·분석 계약을 변경하지 않는다.

실행은 [localhost 호스팅 안내](ai-generated-localhost-security-guide.md)를 따른다. 안내 그림은 페이지에서 보여주기만 하며, 클릭해 업로드 사진으로 선택하거나 분석 요청에 자동 첨부하지 않는다.

구현 환경에서 타입 검사·빌드와 실제 Chromium42개 시험이 통과했다. 1440px·375px에서 두 PNG 디코딩·가로 넘침 없음·안내 그림 클릭 시 파일 선택 미발생·기존 사진 선택/지우기와 재촬영 표시를 확인했다. 별도 빌드 서버에서도 안내 두 장과 실제 업로드·mock 결과 PNG가 표시됐으며 CSP 위반·페이지 오류·외부 요청은0건이다. 실제 분석 모델 호출은 수행하지 않았다. 독립 읽기 전용 코드·이미지 검토에서 발견 사항이 없었다.
