# 해커톤 마무리 상태

GUI·MediaPipe/GPT 파이프라인, reference 원본/표시본, LAN 서버와 요청별 마이크로초 보관, 관절 한국어 안내·목록·이미지 확대를 main에 반영했다. 실제 로컬 HTTP 분석과 핫스팟 휴대폰 결과 표시는 확인했으며 공개 Pages는 실제 분석을 제공하는 서비스가 아니다.

모바일 분석 요청은 비동기202 접수와 짧은 job 조회로 결과를 받는다. 실제 시험 접수0.14초/feedback200 약20초, backend35개와 production build 통과. 기존 동기API는 유지한다. 기기·네트워크 전체에서 연결 안정성을 보장한 시험은 아니다.

## 후속 과제 (미구현/미확정)

- 공개 HTTPS 분석API, 인증·TLS·사용량 제한 및 Pages의 실제 분석 연결 (#10)
- 원본·assessment.json·query_landmarks.json의 GUI 다운로드와 공개 파일 계약 (#2)
- GUI 운동 선택 및 최종 bul/zip reference ID/version·손 방향/미러 정책 (#2)
- API·GUI·pipeline 폴더와 담당 경계의 최종 공동 합의 (#3); 현재 구현 구조는 유지
- 정지 사진 교정 목표점의 정확성·3D 동작 검증

해커톤 종료에 따라 위 이슈는 미완료 상태를 명시하고 범위 종료로 닫는다. 구현 완료로 표시하지 않으며 필요하면 이 문서와 기존 이슈를 근거로 다시 추적한다. 4단계 설명 요청 #12는 댓글 답변 완료로 닫는다. 개인사진·키·로그·IP는 공개 자료에 포함하지 않는다.
