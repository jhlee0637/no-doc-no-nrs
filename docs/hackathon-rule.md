1. 참가팀 구성과 현장 참여

    한 사람은 한 팀에만 소속될 수 있습니다. 행사 시작 후 팀원 추가나 다른 팀으로의 이동은 허용하지 않습니다.
    팀원 불참이나 중도 이탈이 발생하면 운영진에게 알려 주세요.
    팀별로 주력 평가를 받을 트랙 하나를 선택합니다. 두 트랙에 해당하는 프로젝트는 핵심 문제와 사용자 가치를 기준으로 선택합니다.

2. Only Codex — AI 코딩 도구 사용

3. 해커톤 시작 시 빈 GitHub 저장소 등록

모든 팀은 해커톤 시작 시점에 코드와 기존 커밋 이력이 없는 새로운 빈 GitHub 저장소를 등록해야 합니다.

    저장소 생성 시 README, 라이선스, .gitignore 자동 생성을 선택하지 말아 주세요.
    등록 후 해당 저장소에서 개발 내용을 커밋하고, 최종 제출까지 동일한 저장소를 사용해야 합니다.
    운영진은 등록 당시 상태와 이후 커밋 이력으로 개발 과정을 확인합니다. 이력을 삭제하거나 재작성해 개발 과정을 확인할 수 없게 해서는 안 됩니다.

    최종 제출에는 동일한 저장소 링크를 포함해야 합니다. 운영진과 심사위원이 확인할 수 있도록 필요한 접근 권한을 제공해야 하며, 구체적인 권한 설정과 등록 방법은 별도 안내합니다.
