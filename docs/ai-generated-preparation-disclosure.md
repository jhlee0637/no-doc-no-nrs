# 사전·기존 작업 공개

이번 최초 커밋은 새 저장소에서 새로 구현한 앱 기능이 아니라 기존 계획 저장소의 공개 준비물을 복사한 반입 기록이다. 이전 Git 이력을 가져오지 않는다. 행사 플랫폼 등록 시점과 등록 완료 여부는 참가팀이 별도로 확인해야 하며, 이 커밋이나 문서가 등록 완료의 증거는 아니다.

최초 반입에 포함됐던 외부 도구 조사 자료는 현재 운영 문서에서 제외했다. 과거 반입·조사 사실은 기존 Git 이력에 보존하며, 앱 구현이나 대회 중 사용 성과로 계산하지 않는다.

파일의 작성·수정 시각과 Git 최초 반입 시각은 다르다. 본문 또는 YAML의 time을 새 저장소의 최초 구현 시각으로 해석하지 않는다. 본 문서와 공개 사본 정리는 반입 시 작성한 준비물 구분 작업이며 앱 기능 개발은 아니다.

## 반입 전 확인한 검증과 한계

- codex-orchestration 실행기 오프라인 테스트 51개 통과. 임시 SQLite의 claim·이력·중복 억제·예약·정체·후속 상태 처리와 모의 Codex 사건을 검증했다. 실제 로컬 프로세스 종료, CLI 재조회, 감시 중 accept도 확인했다.
- github-monitoring 오프라인 테스트 23개 통과. GitHub·도구 응답을 모의한 검사이며 실계정 간 응답 교환이나 지속 감시 성공의 증거는 아니다.
- Skill 표준 구조 검증 통과. 구조 검증이 에이전트 판단 품질·실제 세션 복구를 증명하지 않는다.
- 기존의 작은 Codex 협업 시험에서는 덧셈 구현·실제 Subagent 리뷰·테스트를 확인했다. 이를 앱 개발·장시간 운영·병렬 앱 구현 성공으로 확대 해석하지 않는다.
- 새 SQLite 실행기의 실제 모델 호출·native session resume·장시간 감시·호스트 재부팅 복구는 미검증이다. 실제 호출이나 지속 실행은 별도 승인 범위와 비용 확인이 필요하다.
- 앱 화면·사진 분석 파이프라인·평가 데이터셋·훈련된 신규 모델은 이 반입에 포함되지 않는다. README는 초기 구상이며 사진 비교형 MVP 등 이후 논의와 계약은 별도 확정해야 한다.

## Codex-only와 외부 자산

구현한 로컬 실행기는 승인된 경우 Codex CLI만 실행하도록 설계했으며, Python·SQLite·POSIX 잠금은 일반 개발 도구다. 라이브러리 의존성은 Python 표준 라이브러리이고 외부 런타임이나 인증 정보를 이 저장소에 복사하지 않았다. Codex는 각 참가자가 자신의 환경·인증·검토한 profile로 사용한다.

등록 후 운영은 자체 Skill·스크립트와 Codex 제공 Skill·MCP/API를 사용한다. 외부 오케스트레이션 플랫폼은 사용하지 않는다. GitHub 조회에는 허용된 일반 도구인 gh를 사용한다. 기존 감시기의 외부 실행 경로는 제거했으며 새 상태 형식은 버전 2다. 반입 전 테스트 수는 과거 기록이고 현재 검증 결과와 구분한다.

Codex 실행·재개 방식 참고: [공식 비대화형 실행 문서](https://learn.chatgpt.com/docs/non-interactive-mode). 외부 자산의 출처는 각 Skill과 참고문헌에 명시되어 있으며, 이 반입에는 외부 모델 가중치·데이터셋·논문 PDF·인증 파일이 없다. LICENSE의 저작권 표시는 보존한다.

## 이후 신규 개발의 기록

등록 후 개발·개선은 이 최초 반입 커밋 이후의 커밋과 검증 증거로 구분한다. 제출 시 기존 준비물과 행사 당일 추가·변경한 앱 기능 및 테스트를 각각 설명한다. 기존 기능을 신규 구현으로 표시하거나 준비물 목록에서 누락하지 않는다.

비공개 etc/, 개인화된 환경·실행 로그, 논문 PDF, 기존 .git 이력은 복사·커밋·공유 대상에서 제외했다. 사용 기록 제출 전에도 별도로 민감정보를 점검한다.
